# SVN 迁移历史范围与 Git 核对优化验收

日期：2026-10-15。所有写入测试均使用临时 Git / SVN 夹具，没有对 EFB 正式工作副本或远程仓库执行迁移、提交、更新或推送。

## 历史范围

- 新目录迁移、当前工作副本首次迁移增加“包含复制前历史”复选框，默认关闭；关闭时使用 `svn log --stop-on-copy`，开启时追溯复制来源。
- 日志分页固定 peg 修订，预检和转换预览显示范围与提交条数；更改范围后旧计划失效。
- 快照模式不显示历史选项；补迁固定从上次节点之后继续，不用复制边界截断后续提交。旧检查点未保存此字段时保持原来的完整祖先范围。
- 迁移预检不再获取并未使用的逐提交变更路径；普通历史页面行为不变。

## 性能与正确性

Git 适配器增加已验证迁移会话。首个快照完整处理；后续按路径、类型、权限、大小和 SHA-256 复用已核对的不可变 blob，只写入变化文件。每个修订仍核对完整 Git 树的路径、模式和对象标识；新 blob 批量读取实际字节并校验。结束时保留完整导出及 SHA-256 比对。

断点恢复核对实际来源缓存、Git HEAD 和完整导出内容，重新建立会话，不盲信检查点。当前工作副本补迁仍保留原来的差异合入流程，不以 SVN 全量快照覆盖 Git 后续改动。

本地单次样本：4 个修订，首版 648 个文件对象和 2 个目录，其中包含 640 个小文件、4 个 768 KiB 二进制文件。后续每版只处理 1–2 个变化文件，复用 646–647 个已核对对象。

| 测量范围 | 原逐版全量导出核对 | 新会话复用 | 耗时减少 |
| --- | ---: | ---: | ---: |
| Git 生成与核对 | 11.589 秒 | 9.202 秒 | 20.6% |

该计时不含 SVN 网络读取、来源扫描和业务检查点写入，不能作为整体迁移提速比例。原始数据见 [git-benchmark.json](git-benchmark.json)。
