# 按钮空白区域点击验证

## 问题与修复

自定义 `.plain` 按钮在未选中、背景透明时，部分标签只对文字或图标命中；另有文件预览按钮把全宽尺寸设置在 Button 外侧，未使标签具有同样大小的点击范围。

- 共用 `WorkbenchSegmentedPicker` 为整个选项的圆角区域设置 interaction content shape。
- 提交文件树把完整文件行的 HStack、宽度和点击区域放到 Button 标签内；勾选框保持独立。
- 历史分支筛选、分支目录及图导航补齐标签内部的点击区域。
- 远程目录选择将名称、留白和元数据列纳入选择按钮；展开箭头仍独立。
- AI 文件选择、忽略候选路径、迁移预览树和小图标按钮补齐既有尺寸内的热区。
- 保留原生 Button、禁用状态及辅助功能语义，不通过额外点击手势代替按钮。
