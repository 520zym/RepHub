### 发现并修复

- 混合 CRLF / LF 的 diff 不能正确拆行，导致 SVN 代码被挤在少数行内：统一解析换行，并补充空行、左右行号回归。
- SVN 历史错误被显示为“暂无提交记录”，状态栏显示“就绪”：历史页和工作区均显示可展开的紧凑错误详情，状态栏标识部分读取失败；无分支/图谱能力的来源移除对应栏目，使用修订号标题。
- 历史页切来源或直接打开其他仓库时可能短暂读取/显示工作区差异：模型记录当前阅读模式，历史模式只读修订差异；回工作区恢复本地差异。
- 长分支、长提交正文和深目录挤占内容：限制顶部标签宽度与目录缩进，正文详情限制高度并滚动；历史收起时补足文件区的来源切换入口。
- SVN 默认日志范围受工作副本 BASE 影响、可能遗漏尚未更新的最新提交：无指定修订时显式读取 `HEAD:1`，保留原有数量限制；已用另一个本地工作副本提交、当前副本不更新的场景回归。
