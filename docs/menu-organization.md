# 菜单与功能入口

菜单按当前窗口选中的 Git / SVN 绑定提供操作；不把 Git 的暂存、推送或分支管理强套给 SVN。所有写操作仍经过原有预检和确认。

应用统一使用简体中文。安装包在 `Info.plist` 中声明 `zh-Hans` 支持与默认语言，系统生成的文件、编辑、显示、窗口、帮助菜单及其标准子项随应用使用中文，保留系统快捷键、编辑操作和窗口管理行为。RepHub、Git、SVN 等产品和技术名称保留原名。

| 入口 | 职责 |
| --- | --- |
| 文件 | 新建窗口、打开仓库、在新窗口打开、最近打开、关闭仓库 |
| 显示 | 工作区、提交历史、提交面板、差异显示选项 |
| 仓库 | 刷新、提交、获取/更新、推送、分支与合并、本地改动、搜索、比较、AI 审查、关联、迁移、仓库设置 |
| RepHub → 设置 | 外观、AI 与场景、迁移作者通讯录 |
| 仓库名称下拉 | 打开、切换、最近打开、关闭及当前路径 |

## 聚焦功能页

推送、分支与合并、暂存区、冲突、比较版本、仓库设置共用管理窗口，但入口会指定目标页。页签按适配器能力显示。仓库设置中包含当前仓库的远端和提交身份，以及本地变更检查的控制入口。

顶部工具栏保留刷新、Git 获取/更新或 SVN 更新、Git 推送、提交和 AI 审查；后台迁移存在时提供恢复入口。文件右键保留文件历史、逐行追溯、按块/按行提交、冲突处理、忽略规则等上下文操作。

## 关联与迁移

关联工作副本与管理已关联工作副本位于“仓库”菜单。移除关联只改变绑定，不删除或同步目录文件。

“SVN → Git 迁移”提供新目录迁移、当前工作副本迁移，以及按迁移类型继续已有任务。恢复入口先显示保留的检查点记录，仍可手动选择保留目录或检查点文件。当前工作副本恢复后先完成原范围，再检查并增量补入当前 SVN 版本内的后续提交；应用到当前目录和发布仍需确认预览。
