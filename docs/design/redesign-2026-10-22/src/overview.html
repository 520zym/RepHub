A

留白

Atelier / Reading first
阅读优先
  • 暖纸面与衬线标题，降低工具感，让代码像一页校样。
  • 三栏留白更大，文件树与提交便笺退到代码两侧。
  • 适合长时间阅读差异、写提交说明的安静工作流。
WARM PAPER / MOSS / INK
B

夜航

Nightshift / Precision first
专注优先
  • 深色仪器面板，亮色只留给可操作状态与增删语义。
  • 等宽小标签、紧凑行高与更高的信息密度。
  • 适合夜间、长时间盯代码与偏爱键盘路径的开发者。
CHARCOAL / MINT / SIGNAL
C

流光

Canvas / Flow first
流程优先
  • 冷白浮层与克制的靛蓝，把工作区切成清楚的阅读卡。
  • 顶部审阅进度、差异内上一份/下一份，形成浏览节奏。
  • 提交区改为 3 步：说明、目标、范围，降低首次使用门槛。
