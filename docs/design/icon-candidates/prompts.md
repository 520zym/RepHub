# RepHub 图标生成提示词

使用内置 image_gen 工具；transparent_background: false。原图保留工具返回的原始分辨率。

## 01 双源叠合

```text
Use case: logo-brand.
Asset type: one standalone macOS application icon concept for RepHub, a native personal Git + SVN version-control workspace for reading code differences, tracking revision history and bringing two repository sources together.
Design brief: contemporary, youthful, friendly, polished, restrained. A strong simple memorable silhouette that works at 32px. Rounded soft geometry, large filled color regions, no strokes or outlines whatsoever, no sharp corners, no pointed tips, no thin connecting lines, no Git branch diagram, no code brackets, no small UI details. Regions are distinguished purely by color. Mostly flat color with extremely subtle tonal gradients for warmth, not shiny 3D or a rendered plastic toy. Beautiful restrained color relationships.
Composition: square 1024 by 1024 image; precisely front-facing single centered application icon. Pale warm off-white seamless canvas. One large superellipse/squircle app tile taking up approximately 84 percent of canvas width, with generous continuously rounded corners; centered main symbol fills about 65 percent of the tile, with balanced breathing room. No multiple options in one image, no perspective mockup, no labels, no captions, no wordmark, no watermarks, no decorative sparkles, no framing lines, no sharp highlight rims. Soft understated native macOS aesthetic.
Concept: TWO SOURCES ONE WORKSPACE. A light very pale mint app tile. The central symbol consists of exactly TWO oversized overlapping rounded square color masses, one slightly upper left, one slightly lower right, with very large soft corner radii. First mass is lively jade green, second mass is soft saturated sky blue. Their wide overlap becomes a rich teal color region: three large clear color fields total. The silhouettes gently merge into one compact badge while both sources remain readable. No card rims, no document text, no plus sign. Make this an elegant graphic abstract source-control identity, not a literal file folder.
```
