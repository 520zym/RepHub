# RepHub 图标候选第三轮

日期：2026-10-11

根据“版本管理工具的特点没体现出来”的反馈，主体改为明确的提交节点、分支与合并关系。以宽厚色块表现连接，圆形表现提交；尽量保留圆润、无细描边的风格。

- 01 翡翠分支：主线提交与右侧分支，最直接的版本管理识别。
- 02 蓝紫合并：两条版本路径汇入同一个提交。
- 03 分支历史：主线与特性分支分开演进、最终汇合。
- 04 并行修订：横向展开的版本分叉。
- 05 提交汇点：将提交节点嵌入白色分支主体。

优先考虑 01 的简洁识别，或 03 的分支与合并语义。05 的节点存在较强圆环感，是后续需要按“不要明显线条”偏好进一步权衡的部分。
