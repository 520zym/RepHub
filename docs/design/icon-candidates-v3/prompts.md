# 第三轮生成提示词

使用内置 image_gen；transparent_background: false。

## 01 翡翠分支

```text
Use case: logo-brand.
Asset type: native macOS app icon for RepHub, a Git and SVN VERSION CONTROL client.
Non-negotiable subject: an immediately recognizable SOURCE CONTROL BRANCH / COMMIT / MERGE symbol. Show the actual topology of connected commit nodes and branching paths. Not a generic file manager. NO folders, documents, books, app windows, letters, code brackets, abstract beans, swirls or decorative motifs.
User's design requirements: modern, youthful but professional, NO sharp edges, NO outlined drawing, NO fine strokes. Translate the source-control graph into one substantial filled emblem: very broad solid color branches joined to large filled circular commit nodes, all terminations and bends fully rounded. Connecting bodies must be at least half the diameter of commit discs, so they read as filled color areas, never wire-like graph lines. Commit nodes must remain easy to distinguish by size and color, always physically attached to their paths. Exactly two main symbol colors plus neutral background. Opaque flat color surfaces, zero glass, jelly, gloss, shadows inside the symbol, or rainbow gradients. Simple strong silhouette at Dock size.
Composition: one centered standalone macOS icon, square 1024 image. Neutral light gray canvas. One standard rounded-square app tile taking 84% of canvas. Frontal view, no perspective, emblem occupies about 60% of tile. Very deliberate geometry and clear negative space. No text, labels, mockup, watermark or contact sheet.
Tile: porcelain white.
Emblem: classic three-commit VERSION CONTROL FORK. A thick jade-green vertical main trunk on the left connects a large circular bottom-left commit with a large circular top-left commit. From the middle of that trunk, one broad gently curved jade branch sweeps up and right to a large circular top-right commit. Exactly three circular endpoint commits, no fourth node at the split. Bottom-left and top-left commit discs are darker jade green; top-right commit disc is fresh light mint-green. The upper two discs align horizontally. The same filled body attaches all three into one solid recognizable Git branch emblem. No arrowheads. Sophisticated clean modern geometry. Keep trunk and side branch substantial and soft, with a clearly visible rounded fork junction.
```
