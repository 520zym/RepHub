# RepHub 暖灰柔和界面设计稿

日期：2026-10-16。状态：视觉探索，待用户确认；未修改 SwiftUI 页面或正式视觉基准。

用户提供四张 margin 产品截图作为风格参考。本轮借用其暖灰底色、柔和白色工作区域、克制的深色按钮和清晰留白；保留 RepHub 的工作区／历史分离、顶部仓库入口、文件树、Git 图和 SVN 分步检出能力。

## 页面

- [工作区](workspace.png)：左侧当前文件树，中间完整差异，右侧多行提交说明与提交动作。代码阅读是主位。
- [提交历史](history.png)：左侧提交记录与紧凑 Git 图，右上将提交说明和文件树并列，下方保留连续差异区。
- [SVN 浏览与检出](svn-checkout.png)：以选择目录步骤为例，左侧步骤，中间目录和修订信息，右侧检出范围摘要；账号、本地路径分别留在对应步骤。

三张图是同一套风格的不同页面，不是三个互斥方案。图中的代码、提交、数量、分支、作者和服务地址均为示意数据，不代表真实仓库状态。生成图中的细小文字、图标、统计与列表数量不作为实现验收依据。

## 原生落地方向

- 暖灰背景与白色内容面区分区域，不添加可见分割线；图稿里少量输入框或表格淡线不作为正式规范。
- 区域圆角约 12–16 点；输入与按钮更小，避免卡片层层套叠。
- 深炭色用于主要操作，绿色主要用于品牌与成功状态；增删保留浅绿／浅红及正负标记。
- 正文 14–15 点；代码使用等宽字体和约 23 点行高，保留新旧行号。
- 保留分栏可拖动、多行说明展开、长历史分页／追加加载、文件树展开、窄窗适配与无障碍。
- 连接页保留密码显示和历史；执行检出后才显示真实下载状态和速度，目录浏览页不伪造传输进度。
