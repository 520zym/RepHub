# 检出流程、文档预览与历史可读性验收

日期：2026-10-15。环境：macOS 27.0.1 / arm64，Swift 6，原生 SwiftUI + AppKit。

## 本轮实现

- 远程获取拆为连接、SVN 目录选择、本地位置、确认四页；Git 跳过目录选择。首次进入 SVN 目录页自动读取，返回保留已浏览目录，可取消目录读取。
- SVN 密码默认遮挡，眼睛按钮临时显示；步骤、入口或关闭切换时恢复遮挡。展开目录不改变检出目标，点击目录名称才选择目标。
- 目录使用同次 `svn list --xml` 返回的最近修订、时间、作者，不对每个文件夹另行发起日志请求。
- SVN 传输显示已处理文件及平均“写入速度（估算）”：统计确认落盘的普通文件大小，排除符号链接、属性更新、删除、冲突等非内容写入；采用单调时间。它不代表网络下载速率。
- 当前工作区的 PDF、Word、PowerPoint、Excel 交给 macOS Quick Look 只读显示；文件边界、符号链接和 256 MiB 上限由应用层统一校验。历史版本仍使用真实修订差异，不替换为当前本地文件。
- 历史行最小高度 72 pt，标题与元信息分行；右侧提交摘要和文件树采用独立圆角底色及留白。仓库历史的上部区域默认高度 456 pt，仍支持拖动调整。
- 图标保留翡翠分支，光学居中、连接线加粗，重新生成原生各尺寸及 `.icns`。

## 自动验证

本轮针对性验证累计覆盖 **81 个不同测试**（65 个 XCTest、16 个 Swift Testing），分轮修复后通过，没有执行全量测试。

- SVN 获取、目录元数据、认证后历史/更新、文件进度与落盘估算：9 项最终重跑通过。
- 获取向导、迟到响应、自动读取、密码遮挡、展开不改变目标：5 项最终重跑通过。
- 工作区文件服务、真实文件边界、文档分类与超大文档拒绝：6 项最终重跑通过。
- 同时回归了工作区/历史切换、分页、图谱、筛选、传输状态、操作编排及获取业务验证。
- 最终 `scripts/build-app.sh debug` 成功生成 `build/RepHub.app`，`codesign --verify --deep --strict` 与 Info.plist 检查通过；这表示本地产物已生成，不表示已替换其他目录中的已安装副本。
- 修正测试夹具的真实 SVN 修订号；大文件夹具改用稀疏文件，避免错误地以 `setAttributes` 冒充扩容。SVN 测试服务的退出改为有界异步等待，避免清理挂起。

日志保留于本机 `/tmp/rephub-readability-tests.log`、`/tmp/rephub-svn-final.log` 和 `/tmp/rephub-ui-core-final.log`。前一文件包含首次发现的失败；后两文件为相应修正后的通过结果。

## 原生窗口验收

使用独立 bundle identifier `com.zym.RepHub.readabilityQA`，只打开脚本创建的临时 Git 与 `file://` SVN 仓库；未操作正式业务仓库。可重复夹具脚本：[create-readability-fixtures.py](../../../scripts/create-readability-fixtures.py)。

| 场景 | 实际结果 |
| --- | --- |
| SVN 密码 | 测试口令可显示，再切到本地入口返回后已恢复遮挡；连接前清空测试口令 |
| 远程目录 | 展示 r3/r5 与时间；展开“资料”保持原检出目标，点“子模块”才改变目标 |
| 子目录检出 | 在临时父目录成功创建“子模块”，自动打开工作区；`svn info` URL 与选定子目录一致，`svn status` 干净 |
| Git/SVN 历史 | Git 31 条中文长标题和 SVN 2 条子目录历史，行间与元信息未重叠；右侧摘要、文件树、代码区可辨认 |
| 面板调整 | 1440 × 963 原生窗口；详情高度从 372 调至 436 pt，提交列表宽度从 430 调至 750 pt，较窄详情中的标题正常换行 |
| 文档 | 真实 DOCX、PPTX、XLSX、PDF 均显示中文正文/表格/页面，不是文件名占位；未跟踪状态仍可辨认 |
| 预览生命周期 | 发现并修复 PDF 切换历史时重复调用 Quick Look `close()` 引发的系统断言；修复后连续往返和打开 PDF 后退出均通过，无新增崩溃日志 |
| 图标 | 检查重新打包后的 64/128 px 图标，线条和视觉重心已改善，外部透明 |

本机 SVN 检出很快，未截获稳定停留的速度截图；速度数值与文件状态通过真实本地文件统计和专项测试核对。本轮未使用远程业务服务器测量吞吐。旧 Office 二进制格式 `.doc/.ppt/.xls` 已接入同一预览入口，但此次实际文件样本验收为 `.docx/.pptx/.xlsx/.pdf`；具体格式兼容性由系统 Quick Look 决定。
