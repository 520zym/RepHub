RepHub 首个版本：在 Mac 上管理 Git 与 SVN。

## 功能

- 打开、克隆或检出仓库，识别 Git / SVN 共管目录，关联多个工作副本。
- 浏览真实层级的文件树、并排 / 统一代码差异、提交历史与 Git 图谱。
- 按文件核对提交范围，分别执行 Git / SVN 提交、更新，以及 Git 推送和分支合并。
- 将 SVN 迁移到 Git：预览文件与历史映射，利用检查点继续初次迁移，显式补迁后续 SVN 提交。
- 可选 AI 提交说明与代码审查，支持模型 API、Codex CLI 和 Claude Code。
- 原生多窗口、独立代码配色、浅色 / 深色 / 跟随系统外观。

## 下载与安装

需要 **macOS 26 或更新版本**。按 Mac 的芯片选择安装包：

| 设备 | 安装包 |
| --- | --- |
| Apple Silicon（M 系列） | `RepHub-0.0.1-macOS-arm64.dmg` |
| Intel | `RepHub-0.0.1-macOS-x86_64.dmg` |

打开 DMG，将 RepHub 拖入“应用程序”后启动。Git、SVN 使用本机已安装的工具。安装包使用临时签名，尚未经过 Apple 公证。

每个 DMG 均附带 `.sha256` 校验文件。在同一目录下载两者后，可执行：

```sh
shasum -a 256 -c RepHub-0.0.1-macOS-arm64.dmg.sha256
```

Intel 安装包将命令中的 `arm64` 替换为 `x86_64`。完整用法见[项目 README](https://github.com/520zym/RepHub#readme)。
