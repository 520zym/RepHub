# 初始化、管理与关联工作副本

## 初始化未受管理的目录

打开本地文件夹后，如果没有识别出版本控制来源，选择“初始化版本控制”。每次只能选择一种工具；检测失败、已有工作副本或包含嵌套 `.git`／`.svn` 元数据时停止初始化。

- Git：创建本地仓库并指定初始分支，不生成首个提交。原有文件显示为待提交内容。之后可在“仓库管理”中设置仅限此仓库的提交姓名、邮箱与远端地址。
- SVN：填写**已存在仓库下尚不存在的新目录 URL**与导入说明。先验证父目录和连接，创建内容快照，执行一次导入，再检出工作副本。检出内容核对成功且原文件未变化后，保留原目录备份并把工作副本放回原位置。备份路径会显示在结果页。

SVN 初始化会创建远端修订，不是本地 `svn init`。为确保原目录不丢内容，包含符号链接、不能读取的文件或初始化期间内容变化时，不替换原目录。网络中断后无法确认写入结果时显示“需要核对”，不自动重试。已有远端代码请使用“打开仓库 → 远程仓库”浏览并检出。

## 仓库管理

从“仓库”菜单按任务打开“推送…”“分支与合并…”“比较版本…”或“仓库设置…”，操作针对当前选中的版本控制来源。管理窗口直接进入对应页，按适配器能力显示内容；完整入口见[菜单与功能入口](menu-organization.md)。

| 功能 | Git | SVN |
| --- | --- | --- |
| 配置远端与提交身份 | 当前仓库的远端、姓名和邮箱 | 沿用连接的会话凭据 |
| 推送 | 当前本地分支 → 所选远端与目标分支，可设置上游 | 不适用，提交直接写服务端 |
| 暂存 | 按文件暂存、取消暂存、查看真实暂存差异 | 不适用 |
| 分支 | 创建、切换、合并，解决冲突后完成合并提交 | 不套用 Git 分支操作 |
| 冲突 | 编辑文本后标记解决 | 编辑内容冲突后标记解决 |
| 版本比较 | 提交号、分支或标签 | 两个数字修订号（可带 `r`） |

推送不会强制覆盖远端。遇到非快进拒绝，先获取并核对两侧历史，再选择合并等处理。提交与推送仍是两个独立动作；双来源提交不会隐式推送 Git。

暂存与取消暂存限定为明确选择的文件，文件名中的 `*`、`[` 等按字面处理；不修改未选择路径的暂存状态。原有“提交代码”仍按所选文件当前内容建立独立提交范围，暂存区并不取代提交准备窗口的文件确认。

切换／合并分支会检查本地修改和可能覆盖的文件，不自动 stash、reset 或清理工作区。合并先生成待确认结果，保留真实合并父提交。冲突入口可以用本机默认编辑器打开文件；编辑后“重新检查”，再“标记已解决”。标记前检查真实冲突状态和内容，未移除冲突标记时拒绝继续。

首版不提供强制推送、分支强制删除、变基、按行暂存、自动选边覆盖、SVN 树／属性冲突修复及 Git 子模块／外部过滤器操作。复杂冲突保留现场并给出具体原因。这里的限制不会被显示为操作成功。

## 比较两个版本

在管理窗口切到“比较”，填写起止版本，选择变更文件读取差异。适配器将输入固定为 Git 提交号或 SVN 修订号；后续文件差异保持同一比较范围。Git 跟踪比较范围中的改名路径，SVN 删除文件使用仍存在该文件的 peg revision。

差异使用独立代码配色，保留行号、增删背景和横向滚动。比较只读取版本数据，不改变工作副本。SVN 比较也显示仓库根目录或选定目录节点自身的属性变化；该行只表示节点属性，不能当作普通文件打开或提交。

## 关联其他本地目录

在“仓库”菜单选择“关联工作副本…”，选择另一个已经受 Git 或 SVN 管理的本地目录。来源菜单同时显示工具与目录名称；提交、更新和管理都明确作用于具体来源。

关联记录随主项目路径保存，重新打开时恢复。解除关联只移除客户端记录，不删除目录或版本控制数据。关联不会自动复制文件，也不会凭相似提交说明把 Git 与 SVN 记录认定为同一个提交。多来源写操作继续由业务层串行协调，结果分别保存。

## 本地监控与布局

项目打开期间，默认每 30 秒检查全部已关联来源的本地状态；可选择 15／30／60 秒或暂停。自动检查仅在应用前台且界面空闲时启动；手动检查可在后台执行，但两者都会在读取忙碌、仓库写操作或正在展示的工作流期间保持 busy guard。检测到变化后显示刷新提示，保留正在阅读的提交、文件和草稿；点击提示后刷新全部来源。

监控不会自动 fetch、update 或提交。远端变化通过明确的获取／更新入口读取；退出应用后不继续监控。首轮建立基线，单个来源失败会保留错误说明，不冒充没有变化。状态栏展示最近检查时间、正在检查状态，以及按来源保留的最近读取错误。

分栏的宽度和高度按区域分别保存，TAB 切换及应用重启后恢复。窗口暂时变小时只缩小显示范围，不覆盖原先保存的尺寸。

## 验证边界

新增自动化测试只使用内存适配器及临时 Git bare／SVN `file://` 仓库。`python3 scripts/create-management-fixtures.py` 生成同样隔离的原生验收样本，所有远端、工作副本与未管理目录均在系统临时目录，不能替换为业务仓库。

真实服务器的权限、认证、钩子及网络中断时机需要在对应环境另行核对；本地样本的成功不等于已向正式远端推送或导入。
