# RepHub 交互原型

这是 RepHub 的浏览器内高保真交互设计稿，用于体验代码管理的基础流程。它不是正式客户端，不读取本地目录、不执行 Git／SVN 命令，也不发起网络请求。

## 开发与导出

在 `prototype` 目录执行：

```bash
npm run dev -- --host 127.0.0.1 --port 4173
```

导出可独立打开的单文件原型：

```bash
npm run export:html
```

导出文件为 `rephub.html`。

## 可体验的流程

- 从“项目”菜单打开示例仓库，或模拟克隆／检出 Git、SVN 仓库。
- 选择一个本地文件夹后，模拟检测 Git、SVN、双版本控制或未受版本控制状态；未受管理时只能单选 Git 或 SVN，再确认模拟初始化并打开。
- 查看工作区文件、并排或统一差异，以及 Git 提交图和 SVN 修订历史。
- 配置 AI 场景与连接，体验代码审查和提交说明生成。
- 勾选 Git、SVN 或两者作为提交目标，体验部分失败后只重试失败目标。
- 从“帮助”中恢复当前示例仓库的演示数据。

所有仓库、提交、历史、AI 输出和操作结果均为 mock 数据。API 密钥只在当前设置弹窗的内存中存在，不会持久化；场景与非密钥连接设置保存于当前浏览器的 `localStorage`。

原型中的目录选择、版本控制检测和初始化也都是模拟。检测失败与“未受版本控制”是不同状态：失败时只能重试，不会引导初始化。其他版本控制系统只保留后续适配入口，尚未实现。

正式 Swift 客户端、真实 Git／SVN 操作、AI API／CLI 调用，以及旧版 SVN TLS 兼容性验证均属于后续工作。
