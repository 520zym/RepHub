- 自动化浏览器禁止 `file://`，未验证双击文件启动；已验证同一导出 HTML 在本地 HTTP 下运行。脚本、样式与图标已内联，无外部业务服务依赖。
- 未验证真实 Git/SVN、旧 TLS 服务、真实 API／CLI、原生 macOS 行为或屏幕阅读器完整操作。原型的 Git 提交不代表远端 push。

- 已有 Git/SVN/共管记录自动识别并打开；已验证双管控目录进入原 RepHub 工作区。
- 未管控目录进入初始化页，路径明确；Git、SVN 可单选或双选，无目标时不能创建。截图：`public/qa/local-folder-init.jpg`。
- 新 Git 初始化后只显示示例 README 的新增内容，历史为空；生成说明并提交后只有一条首次提交记录，无虚构远端推送。

- SVN 地址为空时阻止初始化；填写后模拟导入和检出，工作区干净，历史为初始导入修订。

- 目录、检测、初始化和文件内容全部是模拟数据，不扫描或修改本地文件，不访问远端；未知自定义路径按未管控演示。
